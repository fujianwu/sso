门户平台通过此 Token 调用 GET /api/portal/apps 获取应用列表。
请求时在 Header 中携带：Authorization: Bearer <your-token>
# 获取应用列表示例 GET /api/portal/apps Authorization: Bearer portal_xxxxxxxxxxxxxxxx... # 响应格式 { "apps": [{ "client_id", "app_name", "app_url", "redirect_uris", ... }], "sso_server": "http://your-sso-server" }
