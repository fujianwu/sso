常见问题
如何接入 SSO？
登录后进入管理后台，在「应用管理」中添加你的应用，获取 Client ID 和 Client Secret。然后参照接入文档完成 OAuth 2.0 对接。使用 Python SDK 的话通常 30 分钟以内可以跑通。
支持哪些认证协议？
目前支持 OAuth 2.0 授权码流程（Authorization Code Flow），这是最安全、最通用的接入方式。暂不支持 SAML。
提供哪些语言的 SDK？
目前提供官方 Python SDK，同时内置了 Flask 和 FastAPI 的集成示例。其他语言可以直接调用 REST API，协议标准化，对接并不复杂。
用户数据存在哪里？
所有数据存储在本平台的 SQLite 数据库中，不会同步到任何第三方。密码使用 bcrypt 加盐哈希存储，永不明文保存。
接入是收费的吗？
完全免费，这是个人项目，面向有需要的朋友开放接入。没有商业化计划。
服务可用性如何？
这是个人维护的项目，尽力保持稳定运行，但不提供 SLA 保证。建议接入时做好降级预案，比如在 SSO 不可用时允许用户通过备用方式登录。
遇到 Bug 或问题怎么办？
请通过联系页面提交，描述清楚问题和复现步骤，会尽快处理。
