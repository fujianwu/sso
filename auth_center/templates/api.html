API 参考文档

完整的 SSO 平台 RESTful API 参考

认证 API

POST /api/auth/login

用户登录接口

请求参数

参数名 类型 必填 描述
email string ✓ 用户邮箱
password string ✓ 用户密码
curl -X POST http://sso.example.com/api/auth/login \ -H "Content-Type: application/json" \ -d '{ "email": "[email protected]", "password": "password123" }'
POST /api/auth/register

用户注册接口

请求参数

参数名 类型 必填 描述
email string ✓ 用户邮箱
password string ✓ 用户密码（至少8位）
GET /api/auth/user

获取当前登录用户信息

请求头

参数名 类型 必填 描述
Authorization string ✓ Bearer {access_token}

OAuth 2.0 API

GET /oauth/authorize

OAuth 授权端点

查询参数

参数名 类型 必填 描述
client_id string ✓ 应用 ID
redirect_uri string ✓ 回调地址
response_type string ✓ 固定值: code
scope string 权限范围
https://sso.example.com/oauth/authorize? client_id=your_client_id& redirect_uri=https://your-app.com/callback& response_type=code& scope=profile email
POST /oauth/token

获取 access_token

请求参数

参数名 类型 必填 描述
code string ✓ 授权码
client_id string ✓ 应用 ID
client_secret string ✓ 应用密钥
grant_type string ✓ 固定值: authorization_code
GET /oauth/userinfo

获取用户信息

请求头

参数名 类型 必填 描述
Authorization string ✓ Bearer {access_token}
curl -X GET http://sso.example.com/oauth/userinfo \ -H "Authorization: Bearer your_access_token"

系统 API

GET /health

健康检查

curl http://sso.example.com/health # 响应示例 { "status": "healthy", "timestamp": "2024-12-09T10:00:00", "version": "2.1.0" }
GET /api/health

详细健康检查（包含数据库状态）

{ "status": "ok", "database": "connected", "timestamp": "2024-12-09T10:00:00" }
