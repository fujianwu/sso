简介

欢迎使用 SSO 统一身份认证平台开发文档。本文档将帮助您快速集成我们的身份认证服务， 为您的应用提供安全、便捷的用户登录体验。

SSO 平台基于 OAuth 2.0 授权码流程，提供 Python SDK 和完整 API，可以方便地与 Flask/FastAPI 应用集成。

安装

使用 pip 安装（Python）

pip install sso-client

快速开始

1. 注册应用

首先，在 管理后台 注册您的应用，获取 Client ID 和 Client Secret。

2. 配置回调地址

在应用设置中配置 OAuth 回调地址，用户授权后将重定向到此地址。

3. 初始化客户端

from sso_client import SSOClient client = SSOClient( client_id='your_client_id', client_secret='your_client_secret', redirect_uri='https://your-app.com/callback' )

4. 生成登录链接

login_url = client.get_authorization_url() # 将用户重定向到 login_url

5. 处理回调

code = request.args.get('code') token = client.get_access_token(code) user_info = client.get_user_info(token)

OAuth 2.0 流程

SSO 平台完整支持 OAuth 2.0 标准，包括授权码模式、隐式模式、密码模式等。

授权码模式（推荐）

这是最安全的授权模式，适用于有后端服务器的应用。

1. 跳转到授权页面 GET /oauth/authorize?client_id=xxx&redirect_uri=xxx&response_type=code 2. 用户登录并授权 3. 重定向回应用 https://your-app.com/callback?code=xxx 4. 用 code 换取 access_token POST /oauth/token code=xxx&client_id=xxx&client_secret=xxx&grant_type=authorization_code 5. 使用 access_token 获取用户信息 GET /oauth/userinfo Authorization: Bearer xxx

单点登录

用户在一处登录后，可以无需再次登录即可访问所有集成的应用。

实现原理：SSO 平台维护用户的登录会话，应用通过验证 access_token 来确认用户身份。

多因素认证

启用 MFA 后，用户除了密码外，还需要提供第二个验证因素（如短信验证码、TOTP 等）。

# 启用 MFA client.enable_mfa(user_id, mfa_type='totp') # 验证 MFA client.verify_mfa(user_id, code='123456')

Python SDK

完整的 Python SDK 文档和示例代码。

from sso_client import SSOClient # 初始化客户端 client = SSOClient( base_url='http://sso.example.com', client_id='your_client_id', client_secret='your_client_secret', redirect_uri='https://your-app.com/callback' ) # FastAPI 示例 from fastapi import FastAPI, Request from fastapi.responses import RedirectResponse app = FastAPI() @app.get("/login") def login(): auth_url = client.get_authorization_url() return RedirectResponse(auth_url) @app.get("/callback") async def callback(request: Request): code = request.query_params.get("code") token = await client.get_access_token(code) user = await client.get_user_info(token) return {"user": user}
